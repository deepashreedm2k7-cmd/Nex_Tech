# Nex_Tech 🚀

### Build Your Resume. Practice Your Interview. Build Your Confidence.

**Nex_Tech** is an AI-powered career coaching platform designed to help students and early-career professionals prepare for the job market.

It brings **resume analysis, skill-gap identification, learning, skill verification, mock interviews, and career insights** together in one platform.

---

## ✨ Features

### 📄 Resume Analysis

* Upload or paste your resume
* Select your target role
* Get an ATS-style resume score
* Identify relevant and missing skills
* Receive line-by-line feedback
* Get actionable resume improvement suggestions

### 📚 Learn & Verify Skills

* Identify skills that need improvement
* Access learning resources
* Follow role-specific learning paths
* Take adaptive 10-question skill checks
* Verify skills after completing assessments
* Add verified skills to your resume

### 🎤 AI Mock Interviews

* Practise technical and behavioural questions
* Text, voice, audio, and video interview modes
* Browser-based speech interaction
* Camera-supported interview practice
* Replay and skip questions
* Receive performance feedback

### 📊 Career Dashboard & Report

Track your career preparation through:

* Resume score
* Target role
* Verified skills
* Interview history
* Career readiness
* Interview performance
* Recommended next steps

### 🤖 Career Coach

Nex, the built-in career assistant, helps users with:

* Resume improvement
* Interview preparation
* Skill-gap guidance
* Learning recommendations
* Behavioural interview preparation
* Career-related questions

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/deepashreedm2k7-cmd/Nex_Tech.git
cd YOUR_REPOSITORY
```

### Open in VS Code

```bash
code .
```

### Run locally

Open `index.html` using **Live Server** in VS Code.

1. Install the Live Server extension.
2. Open `index.html`.
3. Right-click the file.
4. Select **Open with Live Server**.

The application will open in your browser.

## 🌐 Deployment

Nex_Tech can be deployed as a static web application using platforms such as:

* **Vercel**
* **GitHub Pages**
* **Netlify**
* **Cloudflare Pages**

For deployment through Vercel:

1. Push the project to GitHub.
2. Connect the repository to Vercel.
3. Import the project.
4. Deploy.

Future GitHub pushes can automatically trigger a new deployment when continuous deployment is enabled.

Nex_Tech aims to make career preparation **personalized, structured, and continuous** by connecting:

The goal is to help users understand where they are, identify what they need to improve, and continuously build the skills and confidence required for their careers.
